# Lunar Lander

Final project code for a Lunar Lander game 


## Controls

- `W`: thrust
- `A`: rotate left
- `D`: rotate right
- `R`: reset after landing or crashing

## Project Layout

- `lunar_lander_fpga/hardware/`: SystemVerilog source, constraints, and top-level hardware files.
- `lunar_lander_fpga/software/`: MicroBlaze C game code and USB keyboard support.
- `lunar_lander_fpga/vivado/lunar_lander.xpr`: Vivado project file.
- `lunar_lander_fpga/docs/`: Extra notes and diagrams.
- `lunar_lander_fpga/tools/`: Helper scripts used while developing terrain/physics.
